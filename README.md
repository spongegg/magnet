# 磁力任务发射台

一个无需安装依赖的静态网页工具：导入包含磁力链接的文本文件，提取并整理下载任务，然后一键调用系统默认的磁力链接客户端，或复制链接到剪贴板。

## 功能

- 支持选择或拖拽多个 `.txt`、`.log` 文件
- 自动提取以 `magnet:?` 开头的磁力链接
- 自动去重同一文件中的重复链接
- 根据磁力链接的 `dn` 参数显示任务名称
- 支持多个文件分别查看，并可关闭已导入文件
- 一键唤醒系统默认磁力下载客户端
- 一键复制磁力链接
- 所有文件内容仅在当前浏览器中处理，不上传到服务器
- 适配桌面端和移动端浏览器

## 快速开始

### 直接打开

用浏览器打开 [magnet-launcher.html](magnet-launcher.html)，然后：

1. 点击“选择文件”，或将文本文件拖入导入区域。
2. 在任务列表中确认需要下载的内容。
3. 点击“唤醒比特彗星”调用已关联的下载客户端，或点击“复制”手动使用链接。

项目没有构建步骤、依赖或后端服务，直接打开 HTML 文件即可使用。

### 使用本地静态服务器

如果希望通过 HTTP 访问，可以在项目目录运行任意静态文件服务器，例如：

```bash
python -m http.server 8000
```

然后访问：

```text
http://localhost:8000/magnet-launcher.html
```

## 文件说明

| 文件 | 说明 |
| --- | --- |
| `magnet-launcher.html` | 推荐使用的通用磁力任务导入与发射页面 |
| `magnet_links.html` | 已生成的静态磁力任务展示页，包含示例任务 |
| `magnet_links.txt` | 纯文本格式的磁力链接清单 |
| `aria2Downloads.txt` | 下载记录或下载任务文本，包含标题、保存目录和磁力链接 |
| `碧蓝之海.txt`、`Mayday.txt` 等 | 按内容分类保存的磁力链接文本清单 |

## 输入格式

工具会在文本内容中查找以下形式的链接：

```text
magnet:?xt=urn:btih:...
```

链接可以单独占一行，也可以嵌在其他文本中。任务名称优先读取链接中的 `dn` 参数；没有名称时会使用“磁力任务 1”这类默认名称。

## 使用条件

- 使用现代浏览器，建议 Chrome、Edge、Firefox 或 Safari
- 系统中需要安装支持磁力链接协议的下载客户端
- 首次点击磁力链接时，浏览器或操作系统可能需要确认打开方式
- 复制功能需要浏览器允许剪贴板访问；若被拒绝，页面会提供手动复制提示

## 隐私与责任

- `magnet-launcher.html` 只通过浏览器的 File API 读取用户主动选择的文件，不包含上传接口。
- 磁力链接会交给用户系统中配置的下载客户端，具体网络行为由该客户端及链接中的 tracker 决定。
- 项目不提供、不托管任何下载内容，也不保证链接的可用性、安全性或版权状态。
- 请仅下载和分享自己拥有合法权限处理的内容，并遵守所在地法律法规及相关服务条款。
