# 磁力任务发射台

一个纯前端的单页工具，用来从文本文件里提取磁力链接，并唤醒本地下载客户端（比特彗星、qBittorrent 等）。文件只在浏览器内解析，不会上传。页面提供 Tracker 列表获取功能，该功能会向指定地址发起网络请求。

## 功能

- 拖拽或选择文本文件（`.txt` / `.log`），支持一次导入多个
- 自动提取文件中所有 `magnet:?` 磁力链接，并按链接去重
- 以文件为单位分组展示，可通过标签页切换或关闭
- 从链接的 `dn` 参数解析并显示任务名称
- 单条链接支持「唤醒」下载客户端和「复制」
- 批量操作：「复制全部链接」「发射下一个」「重置进度」
- 从默认或自定义地址获取 Tracker 列表，并添加到当前文件的磁力链接

## 使用方法

1. 用浏览器打开 `磁力任务发射台.html`。
2. 把含磁力链接的文本文件拖入上传区，或点「选择文件」。
3. 在列表中查看提取出的任务：
   - 点单条的「唤醒」调起系统默认磁力下载客户端。
   - 点「复制」复制单条链接。
4. 如需添加 Tracker，可在获取地址框中使用默认地址或填写自定义地址，点击「获取 Trackers」，再点击「添加到当前任务」。
5. 使用「发射下一个」逐条唤醒任务；「重置进度」会将当前文件的发射进度归零。

### 批量导入到下载客户端（推荐）

浏览器出于安全限制，无法可靠地连续唤起外部程序。批量任务建议使用客户端自带的批量添加功能：

1. 点「复制全部链接」，复制当前文件的磁力链接（每行一条）。
2. 打开下载客户端粘贴：
   - **qBittorrent**：使用「文件 → 添加 Torrent 链接」（快捷键 Ctrl+O），粘贴多行链接后确定。
   - **比特彗星**：使用「任务 → 添加下载任务」粘贴，或开启剪贴板监视。

「发射下一个」每次触发一条链接。发射进度仅在当前页面打开期间保留，刷新页面后会重置。

## 环境要求

- 现代浏览器（Chrome、Edge、Firefox、Safari 等）。
- 已安装并注册 `magnet:` 协议处理程序的下载客户端。若点「唤醒」无反应，请检查系统中磁力链接的默认打开方式。
- 获取 Tracker 列表需要网络连接；自定义地址必须允许浏览器跨域访问（CORS），且使用 HTTP 或 HTTPS。
- 「复制」功能使用剪贴板 API；若不可用，会降级为弹窗手动复制。

## 工作原理

- 磁力链接提取使用正则 `/magnet:\?.*?(?=magnet:\?|$)/gis`，以每个 `magnet:?` 为起点，匹配到下一个 `magnet:?` 或文本结尾。
- 每条链接会去除首尾空白和末尾多余的 `),.;`，再使用 `Set` 去重。
- 文件之间按原始内容去重，避免重复导入同一份文件。
- 添加 Tracker 时，会跳过链接中已存在的相同 `tr` 参数。

## 隐私

文件读取、磁力链接提取和 Tracker 添加均在浏览器本地完成，不会上传文件内容。点击「获取 Trackers」时，浏览器会访问输入框中的 Tracker 列表地址。

## 项目结构

单文件项目，HTML、CSS、JavaScript 全部内联在 `磁力任务发射台.html` 中，无构建步骤、无外部依赖。
