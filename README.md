# 磁力任务发射台

一个纯前端的单页工具，用来从文本文件里批量提取磁力链接，并一键唤醒本地下载客户端（比特彗星、qBittorrent 等）。整个页面无依赖、无后端，文件只在浏览器内解析，不会上传到任何服务器。

## 功能

- 拖拽或选择文本文件（`.txt` / `.log`），支持一次导入多个
- 自动提取文件中所有 `magnet:?` 磁力链接，并按链接去重
- 以文件为单位分组展示，用标签页切换、关闭
- 从链接的 `dn` 参数解析并显示任务名称
- 单条链接支持「唤醒」下载客户端和「复制」
- 批量操作：「复制全部链接」「尝试全部唤醒」

## 使用方法

1. 用浏览器打开 `磁力任务发射台.html`（双击即可，无需服务器）。
2. 把含磁力链接的文本文件拖入上传区，或点「选择文件」。
3. 在列表中查看提取出的任务：
   - 点单条的「唤醒」调起系统默认磁力下载客户端。
   - 点「复制」复制单条链接。

### 批量导入到下载客户端（推荐）

浏览器出于安全限制，无法可靠地连续唤起外部程序，因此批量任务建议走客户端自带的批量添加：

1. 点「复制全部链接」，把当前文件的所有磁力链接复制到剪贴板（每行一条）。
2. 打开下载客户端粘贴：
   - **qBittorrent**：菜单「文件 → 添加 Torrent 链接」（快捷键 Ctrl+O），粘贴多行链接后确定。
   - **比特彗星**：「任务 → 添加下载任务」粘贴，或开启剪贴板监视让它自动识别。

「尝试全部唤醒」会按间隔逐个触发链接，能否连续弹出取决于浏览器和系统的拦截策略，作为备选。

## 环境要求

- 现代浏览器（Chrome、Edge、Firefox、Safari 等）。
- 已安装并注册了 `magnet:` 协议处理程序的下载客户端。若点「唤醒」无反应，请在系统设置中检查磁力链接的默认打开方式。
- 「复制」功能使用剪贴板 API；在非 HTTPS 或 `file://` 环境下若不可用，会自动降级为弹窗手动复制。

## 工作原理

- 磁力链接提取用正则 `/magnet:\?.*?(?=magnet:\?|$)/gis`：以每个 `magnet:?` 为起点，非贪婪匹配到下一个 `magnet:?` 或文本结尾。这样即便链接首尾直接拼接、中间无空白，或 `dn` 里含未编码空格，也能正确切分。
- 每条链接会 `trim` 首尾空白并裁掉结尾多余的 `),.;`，再用 `Set` 去重。
- 文件之间按原始内容去重，避免重复导入同一份文件。

## 隐私

所有文件读取和链接提取都在浏览器本地完成，页面不发起任何网络请求，也不上传文件内容。

## 项目结构

单文件项目，HTML、CSS、JavaScript 全部内联在 `磁力任务发射台.html` 中，无构建步骤、无外部依赖。
